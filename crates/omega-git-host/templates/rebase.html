Upstream rebases

Each project is a soft fork. Its configured local default branch is rebased onto the matching branch from the fetch-only upstream remote. Conflict-free rebases are completed by omega-loop; the project's recurring chat is woken on every run to verify the build and resolve any conflicts.

Safety model

upstream is fetch-only by convention. A writable fork mirror is a distinct remote. The scheduler refuses to start a rebase when the default-branch worktree has uncommitted changes.

Status

queued

running

recurring chat was woken to verify the build
