Upstream rebase cron

Keeps each cron-jobbable project's main branch in sync with upstream. When upstream has moved and a plain fast-forward is possible, omega-loop does it without the model. When the local main also carries commits upstream doesn't have (diverged), the project's dedicated upstream rebaser chat is woken to rebase main onto upstream — and to resolve any merge conflicts itself.
