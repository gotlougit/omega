# cli

Minimal TUI primitives adapted from tau crates.

Provides style types, a diff-based screen renderer, and a terminal prompt with
block-based output zones for building terminal user interfaces.

## Modules

- `screen` — diff-based screen buffering and rendering
- `style` — styled text, blocks, alignment, and width calculations
- `term` — raw terminal handling and event loop
- `emulator` — output zone management
